## Highest-priority remaining theorem: the Gamma_1 cusp count

Prove, for N >= 5:

    2 * gamma1GeometricCuspCount N = gamma1CuspSum N
    gamma1CuspSum N = sum_{d|N} phi(d) * phi(N/d).

Then invoke
`gamma1CuspForms_dimension_formula_prime_product_of_cusp_count` directly.
This would finish the classical nonexceptional Gamma_1 formula; N <= 4 is
already analytically zero. Handle N=4 separately: twice its actual cusp count
is 6, while the totient convolution is 5.

Suggested counting route: cosets of Gamma_1(N) are primitive first columns
modulo N; adjoining -I identifies opposite columns. Translation sends
(a,c) to (a+j*c,c). For d=gcd(c,N), the upper entry is a unit modulo d,
giving phi(d) choices; there are phi(N/d) possible c values. Quotient by sign,
checking the exceptional fixed cases before dividing by two. This is a proposed
route, not a Lean proof already supplied.

For the sign exception, a fixed unipotent orbit needs 2*c = 0 modulo N and
2*a = 0 modulo gcd(c,N). Primitivity forces the possible positive exceptional
levels into N <= 4. At N=4 the single fixed orbit accounts for (5+1)/2 = 3.
Useful existing APIs include `Nat.totient_div_of_dvd` (counts residues with a
fixed gcd), `ZMod.unitsMap_surjective` (lifts units through divisor moduli), and
`ZMod.eq_unit_mul_divisor` (normalizes a residue to a divisor using a unit).
For lifting determinant-one matrices from Z/N, a candidate upstream resource is
[`NormalizerDelta/SL2Surj.lean`](https://github.com/F-Najman/normalizer-lean/blob/1f4c27ec11da475383f69e6f82e2837a0cb54fd0/NormalizerDelta/SL2Surj.lean).
The cached upstream tree contains that file, and XNOrder references its
`redSL_surjective` API. This lifting file was not inspected or ported here.
